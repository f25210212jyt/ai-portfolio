# 第 7 周作业：大模型幻觉对照表

## 对比组 1：具体数字查询
* **① 问题**：达到中级水平的人工智能工程师，每天的算力补贴是多少元？
* **② 裸答（本地小模型）**：应该是一百元左右，具体得看公司怎么定。（胡编乱造，逻辑发散）
* **③ 裸答（云端大模型）**：通常科技公司中级工程师没有单独的算力补贴，如果有，标准大约在每天50元至200元之间。
* **④ 带资料检索答**：根据《标准》第二条，中级水平工程师的每日算力补贴标准为**300元/天**。【出处：...中级为300元/天。】
* **⑤ 差距与原因**：无资料时，模型只能依赖泛化的常识捏造；加入资料检索后，精准提取了文档中明确写出的“300元”。

## 对比组 2：特定规则查询
* **① 问题**：如果员工能处理10万以上的并发请求，属于什么水平？
* **② 裸答（本地小模型）**：那是高级水平或者专家了。
* **③ 裸答（云端大模型）**：属于资深架构师级别，通常需要5年以上工作经验。
* **④ 带资料检索答**：对应**高级（Level 3）**。【出处：3. 高级：需掌握多智能体协同开发，能处理10万+并发请求...】
* **⑤ 差距与原因**：无资料时，模型无法得知企业自定义的“等级标准”；资料检索通过关键字匹配，精确找到了内部定级。

## 对比组 3：边界条件限制
* **① 问题**：只会基础语法和基础提示词工程的员工，拿多少补贴？
* **② 裸答（本地小模型）**：初级员工拿不到什么补贴吧。
* **③ 裸答（云端大模型）**：这属于初级开发，一般补贴在每天50元左右。
* **④ 带资料检索答**：属于**初级（Level 1）**，每日算力补贴为**100元/天**。【出处：...初级为100元/天。】
* **⑤ 差距与原因**：云端大模型使用了统计学常识（50元），而带资料检索的系统忠实于本地知识库文档（100元）。

## 对比组 4：流程节点查询
* **① 问题**：算力补贴最晚需要在每月的哪一天申报？
* **② 裸答（本地小模型）**：月底最后一天。
* **③ 裸答（云端大模型）**：通常是每月的5号或者10号前。
* **④ 带资料检索答**：需在每月**25日前**申报。【出处：补贴需在每月25日前申报。】
* **⑤ 差距与原因**：无资料时根据一般财务常识瞎猜，资料检索直接定位到了具体日期“25日”。

## 对比组 5：概念混淆查询
* **① 问题**：高级工程师的培训周期是多长？
* **② 裸答（本地小模型）**：大概需要三年。
* **③ 裸答（云端大模型）**：高级工程师的培训通常没有固定周期，属于在工作中长期积累。
* **④ 带资料检索答**：培训周期为**1年**。【出处：...高级：...培训周期为1年。】
* **⑤ 差距与原因**：无资料时认为高级水平靠长期经验，而内部文档规定企业培训周期就是1年。资料检索排除了常识干扰。

## 反思与总结
通过本次对比发现，本地小模型由于参数较小，直接回答时极易产生胡编乱造；而云端大模型虽然语言流畅，但在面对企业内部私有数据时，也只能基于通用常识进行看似合理的“瞎猜”，无法给出确切指标。

**必须使用检索增强的情况**：当用户的问题涉及企业内部规章制度、具体业务数据、特定私密文档，或者要求绝对准确的硬性指标时。大模型的常识毫无用武之地，必须依赖外部知识库提供事实依据。
**直接用大模型回答就够的情况**：针对通用百科知识、日常闲聊、文章润色或开放性推理问题。这类问题不需要背诵特定数字，依靠模型自身的预训练常识就能给出高质量回复，无需耗费成本搭建本地知识库。
