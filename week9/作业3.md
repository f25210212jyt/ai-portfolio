## 作业 3：W10 预习——三者辨析 + 希望 MCP 接上的 2 个外部工具

### 三句话辨析

1. **Function Calling（模型侧机制）：** 模型根据提示词和工具描述，输出“我要调用哪个函数、参数是什么”的结构化意图，模型本身不执行函数，执行与回喂由程序完成。
2. **MCP（工具侧协议）：** 一套统一外部工具/资源如何被发现、描述、调用和回传结果的协议标准，让不同模型客户端可以接同一套工具服务。
3. **普通 API 调用：** 程序员在代码里固定写好 HTTP 请求地址、参数和处理逻辑，什么时候调、传什么由程序决定，不是模型自主决定下一步。

### 希望 MCP 帮我接上的 2 个外部工具

1. **课程资料检索与词表查询 MCP 服务**
   - 输入：查询词、目标等级、课文文本或文件路径；
   - 输出：生词 HSK 等级、课文生词覆盖率、超纲词列表、相关课程资料片段；
   - 价值：把 W7 的 `retrieve()`、W9 的 `hsk_level` 和 `evaluate_text_difficulty` 统一暴露给不同智能体复用。

2. **GitHub/Gitee 仓库合规检查器 MCP 服务**
   - 输入：仓库地址或本地仓库路径、检查规则（如是否提交 `.env`、是否出现明文密钥、是否缺少 README）；
   - 输出：合规问题列表、文件路径、风险等级与修复建议；
   - 价值：呼应 W8 愿望清单里的“仓库合规检查器”，把密钥/.env 入仓红线做成可自动调用的外部工具。
