## 作业 4（加分选做）：smolagents 5 行映射表

| 我写的 `tool_agent.py` | smolagents 里对应什么 |
|---|---|
| `TOOLS` 字典：名字 → 函数 | `@tool` 装饰器把带类型注解与 Args 文档的函数变成 `Tool`，交给 `ToolCallingAgent(tools=[...])` |
| `SYS` 提示词要求输出 JSON | `ToolCallingAgent` 使用模型原生 tool calling（JSON-like），提示模板在 `prompts/toolcalling_agent.yaml` |
| `parse_calls` 剥围栏、兜底抓 JSON | 框架内部解析 `ChatMessageToolCall`，不用自己写正则 |
| `TOOLS[name](*args)` 执行 + 异常兜底 | 框架按 `Tool.inputs` 校验参数后调用，执行结果进入多步消息 |
| `run()` 手动回喂 + `max_calls` 收口 | `MultiStepAgent` 的多步循环由框架管理步数与停止条件 |

**加分项证据（选做）：** `pip install smolagents` 后，源码位于 `site-packages/smolagents/`，可本地阅读 `ToolCallingAgent` 与 `prompts/toolcalling_agent.yaml`；许可证为 Apache-2.0，引用时注明来源。
